### 🧪 Production Build Showcase

#### 🏫 CampusReserve
A premium smart space allocation and reservation application engineered for seamless university infrastructure management.
* Allows students to safely book and secure premium classrooms and specialized campus laboratory spaces.
* Integrates an **AI-driven recommendation engine** that dynamically evaluates schedules to suggest optimal classrooms for booking.

#### ⚡ [OneMinuteChat](https://github.com/yuclark/1minutechat)
A high-performance, asynchronous anonymous chatting ecosystem built on a multi-threaded Rust server container.
* Engineered a custom connection matchmaking framework with **Tokio** and **Axum WebSockets**.
* Features a strict 60-second queue timeout tracking architecture before executing random match fallbacks.
* Wrapped inside a responsive, glassmorphic dark-mode UI optimized with dynamic status string rotators.

#### 📊 Exclusive Shared Gastos Tracker
A custom, private multi-client financial tracking mobile app designed exclusively for my girlfriend and me to solve standard ledger sync limitations.
* Built utilizing **React Native** and bundled via **Expo Go** for real-time mobile platform interaction.
* Enables seamless, real-time shared logging streams so both users can co-manage and input shared expenses simultaneously.

#### 🛡️ [taskforcebruno](https://github.com/yuclark/taskforcebruno)
An integrated digital ecosystem designed to optimize municipal shelter workflows and veterinary data coordination.
* Built to modernize operations using robust state logic and real-time asset validation tracing.
* Focused on secure role-based permissions and structured tracking systems.

#### 🚌 PUJ Route Optimizer & Mobile Client
An urban transit tracking application designed to map and streamline public utility jeepney routing configurations.
* Coupled with a lightweight mobile client architecture to handle real-time geospatial route rendering.
* Aimed at reducing urban routing friction through optimized network matrices.

#### 🤖 Contextual AI RAG Pipelines
Custom Retrieval-Augmented Generation agent configurations built to stream deep contextualized responses.
* Developed utilizing vectorized document embeddings to isolate and surface targeted information hooks.
* Interfaces are served completely via interactive **Streamlit** multi-media telemetry dashboards.
